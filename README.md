# minərvo.studio

Web de Minervo Studio — estudio de experiencias de marca. Diseño, código y movimiento.

## Flujo de trabajo

- Cada cambio va en una rama nueva.
- Se revisa y se integra a `main` con un pull request.

## Estructura

- `index.html` — home one-page. El scroll dirige las formas: arman la ə (inicio), caen en caos (trabajo), construyen cada servicio, forman la grilla op-art (manifiesto) y vuelven a la ə (contacto).
- `prototipos/minervo-se-toca.html` — prototipo de la interacción firma: formas con física y sonido que se ensamblan en la ə.
- `brand/` — sistema visual 2026: guía de marca, tokens y plantillas de Instagram.

## Ver en local

Abrir `index.html` en el navegador, o servir la carpeta:

```
npx serve .
```

Depende de Matter.js (cdnjs) y Google Fonts (Geist, Geist Mono, Anton).
