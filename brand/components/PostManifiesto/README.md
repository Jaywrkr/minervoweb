# PostManifiesto

Una idea del estudio en bloque, gritada en `poster` (Anton), mayúsculas, sobre `menta` o `rosa`.

- Texto en `on-color`, alineado a la izquierda, máximo 8 palabras.
- Wordmark abajo; sobre menta el punto pasa a `violeta` para no perderse (única excepción a la regla del punto).
- Frases propias, nunca citas de terceros.
- Animación: las líneas entran una por una de abajo hacia arriba.
