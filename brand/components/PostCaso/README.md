# PostCaso

La plantilla principal del feed (70% del contenido): un proyecto real mostrado en grabación de pantalla.

- Fondo `ground` dark o `violeta`. Label `mono` arriba: "caso NN · tipo" y el año.
- Centro: el screen recording en un contenedor `radius-md`. Video de 10–20 s, sin música invasiva.
- Abajo: nombre del caso en `display` a dos líneas, minúsculas, y duración o wordmark.
- Carrusel: slide 1 video, slides 2–4 detalles (móvil, tipografía, una forma animada), último slide el resultado en una línea.
- El consumidor pone: el video, el nombre del cliente y el tipo de proyecto.
